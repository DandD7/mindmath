## Quick Setup

### Step 1: Add Your Icon

Save your icon file (the blue M with green brain logo) to:

```
/workspace/assets/images/icon.png
```

**Requirements:**
- Format: PNG
- Recommended size: 1024x1024 pixels (minimum)
- Square aspect ratio
- Current background color: #1a2332 (dark blue) - matches your logo

### Step 2: Run Setup Script

```bash
npm run setup-icons
```

This will automatically copy your icon to all required locations:
- `assets/images/adaptive-icon.png` (Android)
- `assets/images/favicon.png` (Web)
- `assets/images/splash-icon.png` (Splash screen)

### Step 3: Test

```bash
# Clear cache and restart
npx expo start --clear
```

## App Store Requirements

### iOS App Store
- 1024x1024px PNG
- No alpha channel (transparency)
- No rounded corners
- ✅ Expo automatically handles this

### Google Play Store
- 512x512px PNG
- Can have transparency
- ✅ Expo automatically handles this

### Production Build

When you build for production, Expo will automatically:
1. Generate all required icon sizes for iOS and Android

```bash

```

## Troubleshooting

### Icon not showing after setup?

1. **Clear cache:**
   ```bash
   npx expo start --clear
   ```

2. **Check file exists:**
   ```bash
   ls -lh /workspace/assets/images/icon.png
   ```

3. **Verify file size:**
   File should be >50KB for a 1024x1024 icon

4. **Rebuild:**
   ```bash
   rm -rf .expo
   npx expo start --clear
   ```

### Icon looks blurry on device?

Make sure your source icon is high resolution (1024x1024 minimum)

### Android adaptive icon background mismatch?

Update `backgroundColor` in `app.json` under `android.adaptiveIcon`
